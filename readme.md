# RAPIDC3 - (SAE456) v1.0

This project is a webapp for a fictitious takeaway fast-food restaurant chain called RAPIDC3. This project was carried out in an educational setting.

#### Remote Server

- This version of the application was designed to run on **Oracle 10g** and with a specific private server.  

#### Local PHP and MySQL Server

- If you wish to launch or fork the project on your machine, go to the **mysql-migration** branch.

This version has received some corrections and the database has been updated for MySQL.
